# Repo görünümü

Bu elle hazırlanmış bağlam haritasıdır; üretilmiş kod haritası değildir.

| Yol | İçerik |
|---|---|
| `platform-urun-fikirleri.md` | Dört ürünün özgün fikir ve kararları |
| `FIRST/README.md` | Proje, ekip ve açık kaynak katkısı |
| `STEP/README.md` | Öğrenci/birey/takım freelance pazarı |
| `INTO/README.md` | Proje ve kişisel gelişim mentorluğu |
| `PATH/README.md` | Son aşamadaki yarışma fikri; kapsam açık |
| `.orchestrator/` | Ortak CLI, contract, adapter, run ve katalog |
| `.agents/skills/` | Canonical orchestration skill |
| `.agent/skills/` | Ortak uygulama ve ürün bağlamı skill'leri |
| `.cursor/` | Hafif PM girişi ve bağlam haritaları |

Ürün bağlantıları: `products.md`. Teknoloji durumu ve açık seçimler: `technology.md`. Henüz uygulama kodu, route listesi, DB şeması veya deploy altyapısı yoktur.
